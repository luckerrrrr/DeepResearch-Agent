# Agent 经典范式笔记

## ReAct

ReAct（Reasoning + Acting）由 Shunyu Yao 等人于 2022 年提出，论文发表于 ICLR 2023。核心思想是让大模型交替输出推理轨迹（Thought）和行动（Action）：推理帮助模型制定和调整计划，行动让模型从外部环境（如搜索引擎、API）获取新信息，行动的结果（Observation）再作为下一步推理的输入。

ReAct 的优点是灵活、能根据观察动态调整；缺点是缺少全局规划，面对多跳问题时容易在局部反复搜索，而且步数越多上下文越长、成本越高。

## Plan-and-Solve

Plan-and-Solve Prompting 由 Lei Wang 等人在 ACL 2023 提出，最初用于改进零样本思维链推理：先让模型理解问题并制定计划，再按计划逐步求解。

在 Agent 场景中，Plan-and-Solve 通常表现为“规划器 + 执行器”的两层结构：规划器把复杂任务拆成有序子任务，执行器（常用 ReAct）逐个完成。它的优点是全局视角更好、子任务边界清晰；缺点是计划一旦制定就较难修改，规划错误会传导到后续步骤。

## Reflection

Reflection 类方法让 Agent 对自己的输出进行批判和修正。代表性工作 Reflexion 由 Noah Shinn 等人提出，发表于 NeurIPS 2023，它把环境反馈转化为语言形式的“反思”，存入记忆，供下一次尝试参考，相当于不更新模型权重的“语言强化学习”。

Reflection 能提升输出质量，但会显著增加调用次数和延迟；另外，模型自我评估存在盲区，对事实性错误的识别能力有限，通常需要配合外部证据核查。
